# Template provenance

Requested landing page: https://www.ieee.org/conferences/publishing/templates
Official alternative landing page:
https://cai.ieee.org/2025/manuscript-templates-for-conference-proceedings/
IEEE Author Center:
https://conferences.ieeeauthorcenter.ieee.org/write-your-paper/authoring-tools-and-templates/

The direct IEEE conference-latex-template.zip URL returned an empty body on
2026-11-15. The complete, unmodified IEEEtran distribution was consequently
retrieved from https://mirrors.ctan.org/macros/latex/contrib/IEEEtran.zip .
Its conference skeleton is IEEEtran/bare_conf.tex and its class is IEEEtran.cls.
All distribution files and the downloaded ZIP are retained here.
The report uses documentclass[conference]{IEEEtran}; no class, margin, font-size
or spacing modifications are made. This is a technical report in the IEEE
conference format, not a submission to a specified IEEE venue.
